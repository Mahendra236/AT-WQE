# AT WQE

This folder contains templates and HTML utilities for dataset and test case preparation.

## HTML Files

- DataSet Preparation.v6.html: Dataset preparation template (version 6).
- DataSet Preparation.v7.html: Dataset preparation template (version 7).
- OB TC Creater.html: Outbound test case creator utility.
- Qtest final.html: Finalized QTest export or report page.
- TestCase Preparation.html: Test case preparation template.
- TestCase Preparationv1.html: Test case preparation template (version 1).

## Excel Templates

- DataSet Preparation Template.xlsx: Dataset preparation spreadsheet template.
- OBTC Template.xlsx: Outbound test case template.
- Qtest Template.xlsx: QTest import or export template.
- TestCase Design Template.xlsx: Test case design worksheet.
